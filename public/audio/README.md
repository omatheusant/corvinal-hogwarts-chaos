# Música ambiente

O player em `src/components/site/music-player.tsx` procura o arquivo:

```
public/audio/tema.mp3
```

Coloque aqui uma faixa instrumental de uso livre (o player não toca nada
sozinho — só depois que a pessoa clica em "play" — então qualquer música
calma funciona bem). Sugestões com licença de uso livre:

- **Pixabay Music** — https://pixabay.com/music/search/medieval%20ambient/
  e https://pixabay.com/music/search/fantasy/ (uso livre, sem atribuição
  obrigatória).
- **Incompetech (Kevin MacLeod)** — https://incompetech.com/music/royalty-free/music.html
  — filtre por humor "Mystical". Licença Creative Commons BY: exige
  creditar "Kevin MacLeod (incompetech.com)" em algum lugar do site (ex.:
  rodapé), a menos que se compre a licença sem atribuição.

Sem o arquivo `tema.mp3`, o player continua aparecendo no canto da tela,
mas com os controles desabilitados.
