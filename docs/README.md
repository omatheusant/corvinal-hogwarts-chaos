# Documentos de contexto (opcional)

Esta pasta é o lugar esperado para documentos de contexto narrativo da
campanha, se você tiver algum. Nenhum existe neste repositório no momento.

Se adicionados, os seguintes nomes são reconhecidos como referência ao
redigir conteúdo institucional e biografias (nenhuma automação os lê
diretamente hoje — é uma convenção para quem for escrever o conteúdo real
pelo `/admin`):

- `CHARACTER_INDEX.md` — índice de personagens e suas casas confirmadas.
- `WORLD_AND_LORE.md` — lore geral do mundo/campanha.
- `ART_DIRECTION.md` — direção de arte e referências visuais.
- `CURRENT_TIMELINE.md` — linha do tempo atual da campanha.
- `CANON_DANTE.md` — cânone específico do personagem Dante Beaumont.

## Regras ao usar esses documentos

- Informação fornecida explicitamente nestes arquivos tem prioridade
  sobre qualquer exemplo já presente no site.
- Sugestões, rascunhos ou ideias soltas nesses documentos **não** devem
  virar acontecimentos confirmados do RPG sem confirmação.
- Não publique segredos, traumas privados, sociedades clandestinas ou
  qualquer informação conhecida apenas pelos jogadores (não pelos
  personagens).
- Só cadastre alguém como membro da Corvinal no `/admin` se a casa dessa
  pessoa estiver confirmada nestes documentos — mencionar alguém não
  basta.
